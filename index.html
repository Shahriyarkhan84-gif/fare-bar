    iPhone does not let any app read another app's screen. This shortcut does it with one tap: it takes a screenshot of the request, reads the text and sends it to Fare Bar.

    1. Open the Shortcuts app and make a new shortcut called “Fare Bar scan”.
    2. Add these actions in order: “Take Screenshot”, “Extract Text from Image”, “URL Encode”.
    3. Add “Open URLs” and set it to the scan link below, followed by the URL Encoded Text. The text stays on your phone: it goes after a #, which is never sent to the server.
    4. In Settings → Accessibility → Touch → AssistiveTouch, set a Custom Action (for example Double-Tap) to the “Fare Bar scan” shortcut.
    5. When a request appears, do that tap. Fare Bar opens with the rate, miles and profit filled in.

    Add a button to your iPhone Control Centre that opens the fare bar.

    1. Open the Shortcuts app and make a new shortcut with the action “Open URLs”.
    2. Paste the app link into the shortcut and name it “Fare Bar”.
    3. Swipe down from the top-right corner to open Control Centre.
    4. Tap +, then “Add a Control”, choose Shortcut and pick “Fare Bar”.

    Install on Home Screen

    iPhone only. This downloads a configuration profile that adds the Fare Bar icon. Then open Settings, tap “Profile Downloaded” and Install.
