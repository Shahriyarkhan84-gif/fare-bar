# Fare Bar

A slim fare bar for delivery drivers. Type the fare, miles and minutes, and it shows:

- **Per mile** = fare ÷ (miles × 1.5) — the extra half covers the return trip
- **Per hour** = fare ÷ minutes × 60
- **ACCEPT / REJECT** — accept when per mile is at or above your minimum (default £1.50)

Your numbers are remembered on the device. It is a single `index.html` with no build step.
